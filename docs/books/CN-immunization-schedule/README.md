## Overview

The National Immunization Program (NIP / 国家免疫规划) provides **11 vaccines** preventing **12 diseases** for children aged 0–6, all free of charge. Key vaccines for newborns (0–6 months) include:

- **HepB** (乙肝疫苗) — birth, 1mo, 6mo
- **BCG** (卡介苗) — birth
- **IPV/bOPV** (脊灰疫苗) — 2mo, 3mo, 4mo
- **DTaP** (百白破疫苗) — 3mo, 4mo, 5mo
- **MPSV-A** (A群流脑多糖疫苗) — 6mo
