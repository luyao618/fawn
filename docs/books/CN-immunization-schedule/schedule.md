## Notes

- 2020年起，脊灰疫苗程序调整为"2剂IPV+2剂bOPV"（前两剂为灭活疫苗注射，后两剂为口服减毒活疫苗）
- Since 2020, polio schedule changed to 2 doses IPV (injection) + 2 doses bOPV (oral)
- 如使用乙脑灭活疫苗(JE-I)替代减毒活疫苗，则为4剂次程序
- If using inactivated JE vaccine (JE-I) instead of live, it's a 4-dose schedule
- 如使用甲肝灭活疫苗(HepA-I)替代减毒活疫苗，则为2剂次程序
- If using inactivated HepA vaccine instead of live, it's a 2-dose schedule
