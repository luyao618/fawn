Developmental milestone checklists from the CDC's "Learn the Signs. Act Early." program.

## Notes
- Milestones represent things most children (75% or more) can do by a certain age.
- These are organized by category: Social/Emotional, Language/Communication, Cognitive, and Movement/Physical Development.
- These materials are not a substitute for standardized, validated developmental screening tools.
